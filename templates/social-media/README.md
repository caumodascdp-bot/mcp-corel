# Modelo de Mídia Social (Social Media Post)

Este modelo orienta a criação de artes digitais destinadas à publicação em redes sociais (Instagram, Facebook, LinkedIn, WhatsApp).

---

## 1. Especificações Técnicas
- **Tamanho Padrão Feed Quadrado:** 1080 x 1080 pixels (proporção 1:1).
- **Tamanho Padrão Stories / Reels:** 1080 x 1920 pixels (proporção 9:16).
- **Sangria (Bleed):** 0 mm (não aplicável para mídias puramente digitais).
- **Margem de Segurança:** 60 pixels de recuo para evitar sobreposição de ícones da interface da rede social.
- **Espaço de Cor:** sRGB (RGB padrão de tela).
- **Resolução:** 72 a 150 DPI.

---

## 2. Blocos de Conteúdo Recomendados
1. **Área Segura Central:** Todo o texto e logotipo devem ficar dentro dos 80% centrais da imagem.
2. **Contraste Visual Elevado:** Cores vibrantes com fundo contrastante para chamar atenção em rolagens rápidas de feed (*feed thumb-stopping*).
3. **Limite de Texto:** Textos diretos, concisos e com hierarquia imediata.
