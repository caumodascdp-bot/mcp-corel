# Testes de Aceitação Ponta a Ponta (E2E): `tests/acceptance/`

## Escopo
Testes de ponta a ponta que simulam o ciclo de vida completo de uma solicitação real de design:
1. Envio de um briefing estruturado completo (ex: Modelo Flyer).
2. Orquestração e cálculo de leiaute pelo motor vetorial.
3. Criação de arte no CorelDRAW e renderização da prévia.
4. Inspeção automatizada de pré-impressão (sangria e curvas).
5. Simulação de aprovação humana.
6. Publicação do PDF final fechado e validação da integridade do arquivo.
